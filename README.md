# (rationalize)

Reverse-engineer a fraction from a decimal number.

![Screenshot](screenshot.png)

**(rationalize)** finds rational approximations using the continued fraction algorithm.

Convergents are ranked by quality: balancing accuracy with simplicity. The continued fraction shows the mathematical representation.

This really should be a [standard library function](https://index.scheme.org/filterset/r7rs_small/%28scheme%2520base%29/rationalize) in any elegant language.
